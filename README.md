# مِرآة — استوديو الصور المتقدم (Mirror Image Studio)

مشروع **محرر صور** يحاكي المحررات الشهيرة (موقع ويب). باك-اند **Python** مبنٍّ على المكتبة القياسية فقط + `Pillow` + `numpy`، وواجهة **HTML/JS** في ملف واحد.

---

## 🚀 التشغيل في Visual Studio Code (خطوات بسيطة)

1. انسخ مجلد `project` (يحتوي `app.py` و `index.html` و `backgrounds/`).
2. افتح المجلد في **Visual Studio Code**.
3. افتح **Terminal** (زري `` Ctrl + ` ``).
4. ثبّت المتطلبات **مرة واحدة فقط**:
   ```
   pip install pillow numpy
   ```
5. شغّل البرنامج:
   ```
   python app.py
   ```
6. افتح المتصفح على: **http://localhost:8000**

> لا حاجة لأي خادم آخر أو لتثبيت Flask. الملفات: واحد للواجهة (`index.html`) وواحد للباك-اند (`app.py`).

## 🗂️ تقسيم المشروع (ثلاث جهات كما طُلب)

- **جهة المعالجة والتحسين والتنعيم** (المصباح): بكسلات + فلتر تنعيم/تحديد + حواف.
- **جهة العمليات الأخرى** (اليمين): هندسة، تحويل صيغ، إزالة خلفية، رسم.
- **جهة الميزات الإبداعية**: دمج صور، خلفيات منتجات، مؤثرات فنية.

---

## ✅ ما يغطيه الحد الأدنى من المتطلبات

- ❯ تحويل بين صيغ الصورة (PNG / JPG / WEBP / BMP / GIF).
- ❯ إزالة الخلفية (خوارزمية flood-fill تلقائية + طريقة اختياريّة rembg).
- ❯ الرسم على الصور (فرشاة + ممحاة + نص).
- ❯ عمليات الصورة: قص، تكبير/تصغير، دوران، ميل (Skew)، قلب.
- ❯ تحسينات البكسل: إضاءة، تباين، تشبع، Gamma، Negative، Log، تسوية هيستوغرام، Threshold، Posterize، Solarize، Duotone، Sepia، HSV، Vibrance، توازن ألوان، Pixelate.
- ❯ فلتر التنعيم والتحديد: Mean و Gaussian (خطي)، Median (غير خطي)، Custom Kernel، Sharpening، Unsharp، Emboss، Contour، Detail.
- ❯ رفع صورتين ودمجهما (Normal / Multiply / Screen / Difference / Add / Soft Light).
- ❯ اختيار خلفية من مكتبة خلفيات منتجات تم إنشاؤها.

## 🎓 التطبيقات المُضافة من المحاضرات المرفقة (DIP Labs)

| المحاضرة | ما أُضيف |
|----------|----------|
| **Lab1** | قراءة/حفظ معلومات، تحويل صيغ، رسم. |
| **Lab2** | قص، تكبير/تصغير، تدوير، نقل/إزاحة (Skew)، دمج، تركيب على خلفية منتج. |
| **Lab3** | `Negative` ، `Logarithm` ، `Histogram Equalization`. |
| **Lab4** | `Mean Filter` و `Gaussian Filter` (خطي)، `Median Filter` (غير خطي)، `Custom Kernel`. |
| **Lab5** | `Laplacian` ، `Difference` ، `Laplacian Edge` ، `Sobel` (X/Y/مقدار)، `Canny`. |

كل خوارزميات الحواف مكتوبة من الصفر (تُفصَّل النواتج وتُطبق NMS و Hysteresis للـ Canny).
